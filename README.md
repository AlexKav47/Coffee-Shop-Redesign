# Local Coffee House Website Redesign

A modern redesign concept for **The Lazy Cow Coffee House**, a local coffee shop website based in Carrick-on-Suir.

This project was built as a self-directed web development project to practise frontend design, layout structure, responsive styling, and creating a more polished user experience for a small local business.

## Disclaimer

This is an unofficial redesign concept created for educational and portfolio purposes. It is not affiliated with, endorsed by, or approved by The Lazy Cow Coffee House. All business names, branding, and related materials belong to their respective owners.
