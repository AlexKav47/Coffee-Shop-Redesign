# Local Coffee House Website Redesign

A modern website redesign concept for **The Lazy Cow Coffee House**, a local coffee shop based in Carrick-on-Suir.

This project was created as a self-directed frontend development project to practise layout design, responsive styling, visual hierarchy, and building a more polished user experience for a small local business website.

The redesign focuses on creating a clean, modern, and welcoming interface while keeping the purpose of the site simple: helping visitors learn about the coffee shop, view key information, and get a better feel for the brand.

## Project Purpose

The goal of this project was to practise creating a polished website redesign for a real-world style business.

Through this project, I focused on:

- Frontend layout structure
- Responsive web design
- UI spacing and alignment
- Typography choices

- Creating a professional portfolio project
